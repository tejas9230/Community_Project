# Community Complaint Portal Using AI

An AI-powered complaint management system for local communities.

## Features
- Submit complaints with GPS location and image evidence
- AI-powered category detection and priority scoring
- Officer assignment and status tracking
- Admin dashboard with heatmap and analytics
- Email notifications on status updates
